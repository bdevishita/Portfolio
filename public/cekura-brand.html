Cekura Design: Brand & Visual Identity

Giving a technical AI testing platform a calm, recognisable visual voice across blog, social, course and product marketing.

RoleFounding Designer
CompanyCekura (YC F24)
Timeline08.2024 – Present
ScopeBrand, illustration, marketing, web

The challenge

Cekura tests and monitors voice and chat AI agents. The subject is dense: red teaming, load testing, CI/CD for voice AI, framework comparisons. The brand had to make that approachable without dumbing it down, and it had to be producible fast by a very small team.

Core system

A restrained palette built around deep ink and a soft violet glow, paired with a geometric display face and a quiet body face. Everything else is optional; these are the fixed points.

Blog covers: a rule-based illustration system

Cekura publishes a lot, on topics like red teaming, Pipecat vs LiveKit, voice load testing and CI/CD for voice AI. Instead of drawing each cover from scratch, I defined a short set of rules so any topic can be illustrated consistently as an SVG:

White background. A single #a6a5ea radial glow. Thin-stroke line illustration. No text inside the graphic. The title lives in the page, the cover only carries the idea.

Illustrative recreations of the cover rules, not the published covers.

Beyond the blog

Architecture diagram

An isometric cube with the Cekura mark

A visual architecture diagram built around an isometric cube carrying the logo mark, with dotted connectors and styled output cards. Delivered as SVG and high-resolution PNG.

Course landing page

Thinkific course page

A landing page and supporting SVGs for Cekura's "Introduction to Software Development Practices" course: dark ink canvas, floating pill badges, stat counters and a dark module grid.

Partnership

A partnership blog hero and a lifecycle diagram that explains the joint workflow at a glance.

Social

LinkedIn product-update carousels

A carousel graphic system for product update posts, built so each release can be turned around quickly while staying on brand.

Website direction

I explored the marketing site across several full-page redesigns, referencing the clarity of Stripe, Linear and Vercel's Geist guidelines. The observability section alone went through light cards, a dark bento, a white bento, SVG and a dark terminal look before settling. The result is a bento grid with expandable feature cards and scroll-reveal sections.

What I'd carry forward

Constraints make a brand faster, not weaker. A few non-negotiable rules (one glow, thin strokes, no text in art) let one designer keep a fast-moving company visually coherent.
